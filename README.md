AQUA SENSE AI
Smart City IoT Flood Monitoring Platform

Project UTS
Muh Rayhan Hot Muft HS
NIM: 2422015

1. Executive Summary

Aqua Sense AI merupakan sebuah platform Smart City berbasis Internet of Things (IoT) dan Artificial Intelligence (AI) yang dirancang untuk membantu monitoring banjir secara real-time melalui sistem sensor cerdas dan dashboard visual interaktif.

Permasalahan banjir di daerah perkotaan masih menjadi isu serius akibat kurangnya sistem monitoring drainase yang efisien dan minimnya informasi kondisi air secara cepat. Banyak daerah masih menggunakan metode pemantauan manual sehingga keterlambatan informasi dapat menyebabkan kerugian besar bagi masyarakat.

Melalui Aqua Sense AI, pengguna dapat melihat kondisi lingkungan secara digital melalui website modern yang menampilkan:

status ketinggian air,
intensitas hujan,
telemetry IoT,
dan visualisasi hardware 3D interaktif.

Project ini menggunakan kombinasi teknologi modern seperti:

ESP32,
sensor ultrasonik,
sensor hujan,
Next.js,
TailwindCSS,
dan Three.js.

Tujuan utama project ini adalah membangun simulasi platform Smart City yang modern, interaktif, dan mudah dipahami sebagai solusi monitoring banjir masa depan.

2. Analisis Masalah
A. Permasalahan Utama

Banjir merupakan salah satu permasalahan terbesar di daerah perkotaan. Penyebab utama yang sering terjadi antara lain:

sistem drainase yang tidak termonitor,
tingginya curah hujan,
keterlambatan informasi,
dan minimnya teknologi pemantauan otomatis.

Banyak wilayah masih mengandalkan pengecekan manual terhadap kondisi saluran air sehingga informasi tidak dapat diterima secara cepat.

B. Dampak Permasalahan

Akibat dari kurangnya monitoring real-time:

masyarakat terlambat menerima peringatan banjir,
kerusakan infrastruktur meningkat,
aktivitas masyarakat terganggu,
dan proses evakuasi menjadi lambat.
C. Bukti Bahwa Masalah Nyata

Masalah banjir hampir terjadi setiap tahun di berbagai kota besar di Indonesia seperti:

Jakarta,
Batam,
Semarang,
dan Bandung.

Pemerintah juga mulai mengembangkan konsep Smart City untuk mengatasi masalah lingkungan dengan teknologi digital dan IoT.

Hal ini menunjukkan bahwa kebutuhan terhadap sistem monitoring banjir modern sangat relevan dan nyata.

3. Spesifikasi Teknis
A. ESP32 Microcontroller

ESP32 dipilih karena:

memiliki koneksi WiFi bawaan,
harga relatif murah,
hemat daya,
dan cocok untuk project IoT.

ESP32 digunakan sebagai pusat pengolahan data sensor sebelum dikirim ke dashboard website.

B. Sensor Ultrasonik

Sensor ultrasonik digunakan untuk:

mengukur jarak permukaan air,
membaca tinggi genangan,
dan mendeteksi potensi banjir.

Alasan memilih sensor ini:

akurat,
mudah digunakan,
dan umum dipakai pada sistem monitoring air.
C. Sensor Hujan

Sensor hujan digunakan untuk:

mendeteksi intensitas hujan,
membantu analisis kondisi cuaca,
dan memberikan data tambahan pada sistem.
D. Website Frontend

Website dibuat menggunakan:

1. Next.js

Dipilih karena:

modern,
cepat,
mendukung React,
dan cocok untuk pengembangan aplikasi web interaktif.
2. TailwindCSS

Digunakan untuk:

mempercepat styling,
membuat desain responsive,
dan menghasilkan UI modern.
3. Three.js

Digunakan untuk:

membuat visualisasi hardware 3D,
simulasi rotasi 360 derajat,
dan meningkatkan pengalaman pengguna.
E. Konsep AI pada Sistem

Artificial Intelligence pada project ini digunakan dalam bentuk simulasi analisis status:

Safe,
Warning,
dan Danger.

Sistem dapat memberikan visualisasi kondisi berdasarkan perubahan data sensor.
